# TreeK

TreeK adds a post tree to Kunena topics. This helps users see the structure of
responses, switch between related posts, and navigate long discussions without
losing the context of who replied to whom.

Starting with version 3.1.0, TreeK allows you to reply to posts and edit your own text posts directly within the discussion tree.

The settings of the tree window allow the user to see the content of a single
post or teasers (beginnings) of all posts on the topic at once, choose a
convenient tree view, etc. without leaving the tree window.

For formatting, links, or attachments, use **F (Open in forum)** to continue in the full Kunena editor.

TreeK is built for Joomla and Kunena Forum.

TreeK Free does not use analytics or send forum posts, user accounts, or browsing activity to TreeK's servers. 
It contacts treek.support to download template files and check version compatibility.

## Editions

TreeK is published in two editions:

- **TreeK Free**: a usable free edition with the topic tree, basic settings,
  post text teaser, text export, and parent-post navigation.
- **TreeK Pro**: adds workflow and comfort features such as screenshot teaser,
  flat view, comfort symbols, BBCode/HTML export, topic monitoring, and extended
  forum-view controls.

The Free edition does not contain Pro implementation code.

TreeK Pro requests may include up to two website URLs. These URLs are used to
manage paid downloads, update access, and support records.

Details and Pro requests are available at:
