# TreeK editions

Этот документ фиксирует разделение TreeK на Free и Pro/Paid-сборку.

## Главное правило

Free-сборка не должна содержать исполняемый код платных возможностей.

Платные пункты могут быть видны во Free-интерфейсе только как безопасная
витрина: disabled-контрол, замок, подпись Pro или всплывающая подсказка. Такая
витрина не должна подключать обработчики, AJAX-задачи, PHP-логику или JS-код,
который реализует платную возможность.

Pro-сборка собирается как полный набор TreeK.

Pro-версию можно полностью протестировать на сайте https://treek.support,
например в теме:
https://treek.support/index.php/forum/examples-of-trees-on-forums/1-example-of-tree.

## UI во Free

Free может показывать полный список настроек, включая Pro-возможности, если
платные пункты представлены как неактивные элементы. Например, во Free можно
показать настройку тизера "Скриншот", но клик по ней должен давать только
подсказку Pro/замок, без выполнения screenshot teaser.

Безопасная Free-витрина может содержать:

- название Pro-опции;
- disabled input;
- CSS-класс для визуального замка;
- короткий текст или tooltip "Pro".

Безопасная Free-витрина не должна содержать:

- реальный обработчик платной функции;
- платный AJAX-endpoint;
- платную PHP-логику;
- JS-функции, которые реализуют платное поведение;
- сохранение платных значений как активных настроек.

## Техническое следствие

Текущий `src/plugin-ajax-treek/media/js/treek.js` содержит Free и Pro-логику в
одном файле. Для настоящей Free-сборки этот файл нужно разделить или обработать
сборщиком так, чтобы платные блоки физически отсутствовали в Free-архиве.

Предпочтительный подход:

- Free собирается по allowlist и дополнительно проверяется на отсутствие Pro-маркеров.
- Pro собирается как полный набор.
- Общий UI настроек должен уметь рендерить Free-safe disabled-элементы без
  подключения платной реализации.
