# TreeK Kunena Overrides Source

Planned home for patched Kunena files and Kunena language fragments.

The current installer reads working override files from:

```text
pkg_treek/treek_resources/kunena_overrides
```

These files are version-sensitive patched Kunena files. Keep the working copy in
`pkg_treek` until the migration plan includes install-script path updates and a
verification pass against the supported Kunena version.
