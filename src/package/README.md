# Package Source

Package-level TreeK source files.

The package builder reads these files from this directory:

- `pkg_treek.xml`
- `treek_install_script.php`
- `language/`

Nested package ZIP files are built from sibling source directories under `src`
and are not stored here.

The legacy `pkg_treek` directory remains a release-layout reference until it is
retired or generated by the build process.
